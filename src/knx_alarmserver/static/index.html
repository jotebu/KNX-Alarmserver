Routing

Die physikalische Adresse beim Routing muss frei und mit ETS abgestimmt sein. Multicast muss im Netzwerk erreichbar sein.

Änderungen werden sofort übernommen und bleiben nach Neustarts erhalten. Ein gespeicherter Eintrag bestätigt noch keinen Telegrammempfang.

ETS-Gruppenadressen

In ETS die Gruppenadressen als XML exportieren (mit Datenpunkttypen, nicht im alten ETS4-Format). Alternativ CSV mit Kopfzeile und Adressspalte. Vollständige .knxproj-Projekte werden noch nicht unterstützt.

Der Import ordnet Namen und Datentypen für künftig empfangene Telegramme zu. Alarmregeln werden dadurch nicht angelegt oder geändert. Fehlende, mehrdeutige oder nicht unterstützte DPT bleiben als Rohwert sichtbar.

Benutzer hinzufügen

Mindestens 12 Zeichen. Beim Bearbeiten beide Passwortfelder leer lassen, um das Kennwort beizubehalten. Änderungen melden den betroffenen Benutzer ab.

Prioritäten

Kleine Zahlen bedeuten hohe Priorität. Alarme und CSV speichern nur die Nummer; die Bezeichnung kann unabhängig geändert werden.

PrioritätBezeichnungAktion

Nummern von 1 bis 999. Bezeichnungen frei wählbar. Vor dem Entfernen oder Ändern einer bereits verwendeten Nummer die betroffenen Alarme auf eine andere Nummer umstellen.

Alarmmatrix

Jede Zeile definiert einen Alarm. Interne IDs werden automatisch vergeben. Änderungen gelten nach dem Speichern sofort, ohne KNX-Neustart. Bei Änderung von Adresse, DPT oder Regel beginnt die Auswertung mit unbekanntem Zustand; die Historie bleibt erhalten.

Beispiel-CSV herunterladenGespeicherte Matrix als CSV

CSV: UTF-8, Semikolon als Trennzeichen, gleiche Spalten wie in der Tabelle, ohne ID. Import ergänzt neue Alarme; doppelte Gruppenadressen und ungültige Zeilen verhindern die gesamte Übernahme. Beispieladressen vor dem Import anpassen.

Operatoren: eq = gleich, ne = ungleich, gt/ge = größer / größer gleich, lt/le = kleiner / kleiner gleich, between/outside = innerhalb / außerhalb, contains = Text enthält, in = Werteliste, monitor = nur anzeigen. Werte als JSON (z. B. true, 50, [20,80] oder "Störung"), Hysterese als Zahl mit Dezimalpunkt. DPT-Feld optional für strukturierte Werte (z. B. status.fault).
