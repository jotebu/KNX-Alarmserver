# GitHub-Projektstand

Der Quellcode liegt in https://github.com/jotebu/KNX-Alarmserver. Aktuelle Projektversion: **0.10.07**.

Installation und Aktualisierung stehen in [README.md](README.md), Änderungen in [CHANGELOG.md](CHANGELOG.md).
GitHub Actions enthält Tests sowie einen Release-Workflow für Versionstags. Ein Commit auf main allein erzeugt noch keinen Versionstag oder Release.
Die Anwendung ist weiterhin eine Inbetriebnahmeversion; der echte KNX-/MDT-Abnahmetest steht aus.

## Pflege

Commit-Titel beschreiben die konkrete Änderung ohne Versionsnummer. Versionsnummern werden zentral in Paketmetadaten, Anwendung und Changelog geführt. Dateinamen und Ordnernamen bleiben versionsunabhängig. Bei jeder weiteren Version wird CHANGELOG.md aktualisiert.
